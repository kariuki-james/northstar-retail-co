## Communication Rules

- **Primary channel:** WhatsApp
- **Response time:** Within 4 hours during working hours (09:00–18:00 EAT)
- **Daily sync:** 15-min standup at 10:00 EAT via video call
- **Escalation:** If no response within 24 hrs, raise in next standup

## Git & Code Conventions

- **Branch naming:** `feat/short-description`, `fix/short-description`, `docs/short-description`

- **Conventional Commits format:**
  - `<type>: <what changed> - <why it matters>.`
  - `"wip" / "updates" are not acceptable messages.`
- **PR rules:** Minimum 1 approval required before merge.

## Deadlines

- Board must be updated **same-day** as work occurs
- PRs must be opened within 2 hours of completing a task
- No commits to `main` branch directly, always via PR

## Conflict Resolution

1. Discuss privately first (DM or 1:1 call)
2. If unresolved, bring to next standup
3. If still unresolved, escalate to course instructor

## Definition of Done (Global)

A task is "Done" when:

- Code is written and passes linting
- PR is opened and linked to the Issue
- At least 1 teammate has approved the PR
- Board status is moved to "Done"
